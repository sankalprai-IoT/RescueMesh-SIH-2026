# RescueMesh — System Usage

RescueMesh provides role-specific operational dashboards for managing disaster-response activities.

## Dashboard Access

After authentication, users are provided access according to their assigned operational role.

The available operational dashboards are:

- Area Admin Dashboard
- Commander Dashboard
- Unit Leader Dashboard
- Responder Dashboard
- Shelter Manager Dashboard
- Shelter Responder Dashboard

Each dashboard presents the functions and operational information relevant to that role.

## Role-Based Operation

The system separates responsibilities between administrative, command, field-response, and shelter operations.

Users interact with the platform according to their assigned permissions and operational scope.
